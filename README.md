# Unit testing multiple HTTP calls

This repo contains the example for unit testing http calls for different setups.

## plainhttp

This folder has an example on how to test plain http request

## httpclient

This has an example for making http request using http client but not using interface to make the calls.

## withiface

This folder has example to make single http call using interface, with unit test.

## multiplehttp

This folder has example for multiple http call in same method and the test.
